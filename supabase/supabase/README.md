# Morrow Supabase backend

This directory is a review-ready Supabase CLI project. It contains ordered SQL migrations and the `auth-anilist` Deno Edge Function. It contains no project URL, service key, AniList client secret, or deployed resources.

Start with [`HANDOFF-SERVER.md`](HANDOFF-SERVER.md) for the schema/policy explanation, required dashboard secrets, migration order, and deployment commands. Apply these migrations only after reviewing them in a development Supabase project.
